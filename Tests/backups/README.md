# Kotlin reference serializer fixtures

These small, invented records were produced by an isolated Kotlin/JVM program
using kotlinx.serialization **1.11.0** and its default `ProtoBuf` instance.
They are reference serializer fixtures, not exported user Mihon backups. No
Android application, APK, manga website, personal data or production Kami
decoder participated in their creation.

`ReferenceBackupProducer.kt` contains independently authored minimal schema
declarations. Field numbers, types and defaults were checked against Mihon
main [`7aacaa349019ff42b8b05403d8beebe94c8f6dfc`](https://github.com/mihonapp/mihon/tree/7aacaa349019ff42b8b05403d8beebe94c8f6dfc).
The [pinned library manifest](https://github.com/mihonapp/mihon/blob/7aacaa349019ff42b8b05403d8beebe94c8f6dfc/gradle/libs.versions.toml)
declares Kotlin 2.4.20 and serialization 1.11.0. The
[backup manga schema](https://github.com/mihonapp/mihon/blob/7aacaa349019ff42b8b05403d8beebe94c8f6dfc/app/src/main/java/eu/kanade/tachiyomi/data/backup/models/BackupManga.kt)
and [update-strategy enum](https://github.com/mihonapp/mihon/blob/7aacaa349019ff42b8b05403d8beebe94c8f6dfc/source-api/src/main/kotlin/eu/kanade/tachiyomi/source/model/UpdateStrategy.kt)
are separately pinned. The fixture declares the same two enum members in the
verified order; independent wire inspection confirms their numeric encodings.

Each fixture has raw `.pb` bytes, a single gzip `.tachibk` member, and a
`.kotlin-decoded.json` expectation file. The JSON is generated by **Kotlin
decoding those protobuf bytes**, with all defaults explicit. Its large integers
are exact JSON decimal numbers; consume them as signed Int64, not Double.
`manifest.json` locks SHA-256 hashes of all three files, producer source and
recipe, and records exact decoded values and authoritative dependency hashes.

| Fixture | Meaning |
| --- | --- |
| `kotlin-defaults` | favorite=true omitted and false explicit; category orders 7 and 4294967301 differ from IDs 101 and 202; source IDs 9007199254740993 and Long.MAX_VALUE; fixed32 chapter values 2.25/3.5; Long progress, order and history duration above Int32; millisecond dates/history; nullable favoriteModifiedAt; ONLY_FETCH_ONCE=1 and initialized=true. |
| `kotlin-categories-only` | No manga field; raw stream starts with category tag 0x12. |
| `kotlin-sources-only` | No manga/category field; raw stream starts with source tag 0xaa 0x06. |
| `kotlin-negative-source` | Long.MIN_VALUE preserves its signed varint identity; nullable favoriteModifiedAt=0 is present and differs from omitted null. |
| `kotlin-empty-root` | Required-at-construction manga=[] encodes to zero protobuf bytes and decodes to empty lists; gzip member is 20 bytes. |

The high/negative values test wire fidelity, not acceptance into a future
domain restore. Preference polymorphism, tracking, memo/reader flags, legacy
structures, unsupported-field counts, source mapping and runtime APK
compatibility are not demonstrated by these minimal fixtures.

For a quick check without Java, compiler, network or production Swift:

```bash
python3 Tests/backups/verify-fixtures.py
```

`verify-fixtures.py` independently inspects raw wire tags and checked values,
verifies gzip CRC/size/full consumption through Python zlib, and checks locked
hashes. It never produces fixture bytes or their Kotlin expectations.

To reproduce all bytes with existing isolated downloads:

```bash
python3 Tests/backups/reproduce.py \
  --tools-dir .git/checkpoints/20261004-backup-decoding/reference-producer-tools
```

For a new checkout, append `--fetch` explicitly. Downloads go only into that
directory. The recipe checks official Adoptium/JetBrains release SHA-256 values
and Maven Central Gradle-module SHA-256/SHA-512 values, extracts a fresh runtime
and compiler into a temporary subdirectory, compiles the fixture producer with
the serialization plugin, reruns it, and requires every output hash to match.
It never installs OS/global SDKs or rewrites these fixtures. JRE/compiler
archives and runtime jars are deliberately outside tracked test data.

The pinned Linux producer uses Temurin **21.0.12.1+1** and Kotlin **2.4.20**,
targets JVM 17, and uses Java `GZIPOutputStream`. Its header has flags=0,
mtime=0, XFL=0 and OS=255. The compressed-byte lock applies to this exact
producer/toolchain; another valid compressor may encode the same protobuf
differently. Normal CI consumes the locked files and does not regenerate them.
